# E-Commerce-Sales-Analysis-Dashboard-Power-BI
🌐 E-Commerce Sales Analysis Dashboard 2025





🔄 Project Overview

This project presents a comprehensive E-Commerce Sales Analysis Dashboard for the year 2025, built using Power BI. The dashboard helps businesses track and understand their sales performance, customer behavior, and operational efficiency by visualizing trends, categories, payment methods, and geographic data.

🎓 Objective

To create a dynamic and interactive dashboard that provides stakeholders with real-time insights into sales trends, order fulfillment, and customer purchasing patterns.

📊 Key Features

Slicers for Product & Category Filtering

KPI Cards: Total Revenue, Total Orders, Total Quantity, Average Order Value

Sales by Category & Product

Sales by Payment Method

Order Fulfillment Status Overview (Completed, Pending, Cancelled)

Geographic Distribution of Sales using map visuals

Time Series Analysis: Sales by Year, Quarter, Month, Day

🔧 Tools & Skills Used

Power BI (Dashboard creation, DAX measures, Visual storytelling)

SQL Server (Data querying and modeling)

Data Cleaning: Excel (initial inspection), Power Query (transformations)

Data Visualization: Interactive visuals and slicers
