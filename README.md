# E-Commerce-Sales-Analysis-Dashboard-Power-BI
🌐 E-Commerce Sales Analysis Dashboard 2025





🔄 Project Overview

This project presents a comprehensive E-Commerce Sales Analysis Dashboard for the year 2025, built using Power BI. The dashboard helps businesses track and understand their sales performance, customer behavior, and operational efficiency by visualizing trends, categories, payment methods, and geographic data.

🎓 Objective

To create a dynamic and interactive dashboard that provides stakeholders with real-time insights into sales trends, order fulfillment, and customer purchasing patterns.

🔧 Tools & Skills Used

Power BI (Dashboard creation, DAX measures, Visual storytelling)

SQL Server (Data querying and modeling)

Data Cleaning: Excel (initial inspection), Power Query (transformations)

Data Visualization: Interactive visuals and slicers

📌 Dashboard Features:

🎛️ Slicers for Interactivity:

Product Category Slicer

Product Name Slicer

These filters help users explore data based on specific product groups or items.

🧮 Key Performance Indicators (KPIs):

Total Revenue

Total Orders

Total Quantity Sold

Average Order Value (AOV) – Derived metric calculated as Total Sales ÷ Total Orders

📊 Visualizations & Insights:

1. Geographic Distribution of Sales (Map)

    A location-based map to show where most orders come from, offering visual insights into high-performing customer locations.

2. Sales by Product Category

    A breakdown of total sales by category (e.g., Electronics, Clothing, Books), identifying which product types drive the most revenue.

3. Sales by Payment Method

    Understand customer preferences across different payment options (e.g., Credit Card, PayPal, Amazon Pay).

4. Order Fulfillment Status Overview

    A visual summary (using column chart ) of order statuses like Completed, Pending, and Cancelled, helping to track operational performance.

5. Sales Trend Over Time (Line Chart)

    Displays the trend of total sales across Year, Quarter, Month, and Day to identify seasonality, spikes, and patterns.
